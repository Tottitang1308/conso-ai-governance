# How Conso works

Conso is designed to turn connected AI activity into understandable, testable guardrails.

1. **Connect:** Link an AI environment.
2. **Discover:** Find the agents in that environment and map what they can do.
3. **Assess risk:** Review agent actions, data access, and possible exposure.
4. **Build and test guardrails:** Draft policies from the findings and test them against example actions.
5. **Human review:** People decide whether to approve and activate the controls.

**In one line:** Connector → agent discovery → risk assessment → tested guardrails → human review.

This repo is a product showcase, not a software package. The animation and linked demo communicate the intended workflow. They do not represent live production connectors, automatic enforcement, or backend services.
